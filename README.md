# Khan Mobile (Android)

A small point-of-sale app: sell, buy, products and reports, with an in-memory database.
Sign in with the fixed account set in `data/Models.kt` (`Auth`).

Build the APK: open the **Actions** tab, run **Build Android APK**, then download the
`inventry-pos-apk` artifact and install `app-debug.apk` on the phone.
